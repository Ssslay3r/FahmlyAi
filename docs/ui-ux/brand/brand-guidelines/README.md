# Fahmly identity

The [approved brand board](approved-brand-board.jpeg) and four original Rafeeq expressions are the visual references accepted in the project chat. The board guides hierarchy, spacing, palette, cards, navigation, and mascot placement; it is not a production interface to copy as one large image.

Use **Fahmly / فهملي**, **Rafeeq / رفيق**, and **Your Smarter Way to Learn.** Keep the tone friendly, intelligent, calm, encouraging, and suitable for university students.

Use blue as the main action color, purple for the brand gradient, cyan for accents, and orange sparingly for tips. Give learning content enough space and use quieter surfaces around it. Preserve the approved mascot's proportions, cap, face, eyes, and gradients.

English and Arabic have equivalent flows. Arabic layouts use RTL; technical abbreviations and filenames retain their own direction. Libyan dialect is a conversational preference, while formal educational terminology remains clear.

Explain mistakes constructively. Show processing, empty, failure, and connection states explicitly. Avoid fake online indicators, completed work, or AI capabilities in production. The prototype uses clearly labelled fictional demonstrations.
