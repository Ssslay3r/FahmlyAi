# Fahmly logo direction

Use the approved blue/cyan/purple Rafeeq mascot with the **Fahmly** wordmark and the tagline **Your Smarter Way to Learn.** The [original board](../brand-guidelines/approved-brand-board.jpeg) is the reference for lockups and app-icon direction.

The prototype composes the [default reference](../mascot/default/rafeeq-default.png) with a live text wordmark. It is a design preview, not a newly traced vector logo. Do not reuse the superseded kit's robot, logo SVGs, or orange tassel.

Keep the mark proportional, avoid distortion, allow clear space around it, and use readable text against both themes. Dedicated production wordmark exports, transparent assets, favicons, and launcher icons remain to be prepared from the approved identity after review.
