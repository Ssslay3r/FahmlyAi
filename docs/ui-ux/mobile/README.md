# Mobile design — future Flutter client

Review the [prototype](../prototypes/index.html) using **Phone view** or a narrow browser window. This is the mobile design reference, not a generated Flutter application.

The design covers onboarding, home, documents and simulated processing, document summary/key points/topics, cited chat, quiz setup/player/results, and profile/preferences. Bottom navigation has Home, Chat, Upload, Quizzes, and Profile, with a central emphasized upload action.

Use the approved Rafeeq expressions through the shared semantic state model. The future Flutter implementation may use the previously discussed Riverpod controller and go_router routing after application initialization; no packages have been installed in this task.

Maintain minimum 44 px touch targets, safe padding under the bottom navigation, readable Arabic text, directional spacing, and reduced motion. Review light/dark themes and both locales; offline prototype font fallbacks differ from final bundled fonts.
