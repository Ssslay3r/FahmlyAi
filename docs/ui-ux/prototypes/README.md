# Interactive design preview

Open [index.html](index.html) directly in a modern browser. Everything is local: no packages, network calls, external fonts, APIs, or build step. Relative CSS and approved images are included in this directory tree.

Review Desktop / Phone, English / Arabic (RTL), and light / dark. Use the design-system screen to view the exact mascot references and inspect every semantic state. Home, Documents, Chat, Summary, Quiz, Results, Profile, and onboarding are interactive.

Upload, processing, chat, citations, scoring, retry, and reconnect are scripted design demonstrations. Local file selection uses the filename only; it does not read or upload content. The preview identifies itself as a design prototype. Refresh resets its temporary data.

The previous external Claude artifact is superseded by this repository-local preview. The archived original assets remain recoverable outside the repository.
