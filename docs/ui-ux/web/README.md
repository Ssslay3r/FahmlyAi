# Web design — future Next.js client

The [interactive prototype](../prototypes/index.html) follows the original board's sidebar, welcome hero with Rafeeq, study shortcuts, recent documents, and light/dark visual direction. New study screens continue that identity.

Active destinations are Home, Chat with Rafeeq, My Documents, Quizzes, and Profile. Subjects, Notes, and Calendar remain disabled Later destinations. The global search opens the document list and filters it. The prototype demonstrates document study, citation navigation, quizzes/results, preferences, and state recovery.

At widths below 900 px, switch to mobile navigation. **Phone view** constrains the same prototype for design review. Arabic mirrors navigation and layout using logical properties. Theme and language controls are available without hiding content.

The future Next.js client will use the same FastAPI backend as Flutter. The prototype has no API routes, server application, AI implementation, or installed dependencies. Its scripted examples must be replaced through explicit service boundaries during production implementation.
